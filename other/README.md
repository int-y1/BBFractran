# Other files

For files that don't fit into any of the other directories.

* `gen_lean.py` reads a holdouts list and holdout number. The output is a Lean file in `BBFractran/other/lean` that represents the holdout. You will want to put the Lean file into <https://github.com/int-y1/proofs/tree/master/BBfLean>.
* `gen_lean_1dpc.py` generates Lean files for holdouts decided by 1DPC. There is a summary file and a file for each holdout.
* `gen_lean_ndpc.py` generates Lean files for holdouts decided by NDPC. There is a summary file and a file for each holdout.
